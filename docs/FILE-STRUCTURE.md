# File Structure

```
Spectrogram Studio/
├── README.md                          Overview: screenshots, pipeline diagram, links
├── Spectrogram Studio.md              The original brief (with assumptions and changelog)
├── project.yml                        XcodeGen spec, the source of truth for the Xcode project
├── Spectrogram Studio.xcodeproj       Generated from project.yml (committed so it opens without XcodeGen)
│
├── Spectrogram Studio/                The Mac app
│   ├── App/
│   │   ├── SpectrogramStudioApp.swift   Entry point: main window, menus and shortcuts, Settings scene (⌘,),
│   │   │                                Help ▸ Send Feedback, launch arguments for screenshots
│   │   └── Prefs.swift                  Every preference key and default; FeedbackStore (local JSON-lines file)
│   ├── DSP/
│   │   ├── FFT.swift                    Real FFT wrapper over vDSP (plain DFT scaling); window functions
│   │   ├── STFT.swift                   STFTGrid (frame ↔ time ↔ bin maths); Resynthesizer (masked inverse STFT, WOLA)
│   │   ├── Analysis.swift               AnalysisSettings; Analysis (levels, MFCC, pitch per frame); Analyzer (parallel)
│   │   ├── MFCC.swift                   Mel filterbank + log + DCT-II
│   │   ├── PitchTracker.swift           YIN with an FFT-based difference function
│   │   └── FrequencyScale.swift         Linear / log / mel axis warps; note names
│   ├── Model/
│   │   ├── FilterMask.swift             BrushStamp, FilterStroke, FilterMask (undo/redo), MaskRaster (Int8 half-dB grid)
│   │   └── Studio.swift                 The document: load, analyse, paint → partial re-render → re-analyse,
│   │                                    playback, zoom/scroll, export; PlayheadClock, PointerState
│   ├── Audio/
│   │   ├── AudioFile.swift              Decode any audio/video via AVAssetReader (mono); write WAV
│   │   └── AudioPlayer.swift            AVAudioSourceNode player holding original + filtered; gapless swap
│   ├── Views/
│   │   ├── ContentView.swift            Window layout, toolbar, brush popover, status bar, drop zone
│   │   ├── SpectrogramView.swift        AppKit spectrogram: drawing, axes, ruler, painting, seek, zoom/scroll
│   │   ├── Rendering.swift              Colour maps; TimelineMapping; spectrogram / mask / MFCC bitmaps
│   │   ├── TimelineRows.swift           MFCC heatmap row and pitch-track row (Swift Charts), playhead overlay
│   │   ├── InspectorView.swift          Live panel: pitch readout, spectrum slice and MFCC bars (Swift Charts)
│   │   ├── SettingsView.swift           Settings tabs: Analysis, Display, Brush, Playback & Export
│   │   └── FeedbackView.swift           Feedback sheet
│   └── Resources/Assets.xcassets        App icon (generated by scripts/make_icon.swift)
│
├── Tests/
│   ├── DSPTests.swift                   FFT, reconstruction, cuts, partial render, mask, analysis, YIN, MFCC, decoding
│   └── InteractionTests.swift           Mouse painting and ruler seeking on the view; live playback
│
├── web/
│   └── index.html                       The website: the same pipeline in JavaScript, one self-contained page
│
├── scripts/
│   ├── make_demo.swift                  Synthesises "Demo Melody" as WAV and MP4
│   ├── make_icon.swift                  Draws the app icon at every size
│   ├── screenshots.sh                   Captures docs/images/ from the Release build
│   └── window_id.swift                  Finds the app's window number for screencapture
│
└── docs/
    ├── INSTRUCTIONS.md                  Setup, run, test, use
    ├── SYSTEM-DESIGN.md                 Architecture, flows, decisions, limits
    ├── FILE-STRUCTURE.md                This file
    └── images/                          README screenshots
```

`build/` (Xcode output, demo media) is ignored by git.
